# SEO and Sitemap Plan

The current website is a development concept, so robots.txt blocks indexing by design. The sample garment pages are also marked noindex because they are fictional portfolio entries.

When approved for production, update `astro.config.mjs` with the real domain and generate a sitemap for only verified public pages. Proposed URLs:

- `/`
- `/collections/`
- `/collections/agbada/`
- `/collections/senator/`
- `/collections/kaftan/`
- `/bespoke/`
- `/atelier/`
- `/commission/`
- `/contact/`
- `/faq/`

Do not index provisional policy content, example.com URLs or design-study pages until the true business information is ready. Include original photographs, authentic descriptive alt text and image dimensions in the final SEO pass.
